---
name: literature-review
description: Survey what papers say about a topic, with consensus and disagreements
when_to_use: "state of the art", "what does the literature say", "recent work on", "literatür taraması"
---
1. Search arXiv with 3-5 English query variants (synonyms, key method names, key authors once found).
   Also search local PDFs with search_library.
2. Pick 5-10 relevant papers; for each read the abstract and, if available locally, the conclusion.
   Register each with add_source (origin arxiv, locator = arXiv id + section).
3. Build a table in your notes: paper | year | method | main result (with numbers) | limitations.
4. Group into themes; state where results agree, where they conflict, and possible reasons
   (different datasets, assumptions, regimes).
5. Report: summary of consensus -> themes -> open problems; cite every claim [n]. Note the cut-off date of the
   offline arXiv index, since newer work may be missing.
